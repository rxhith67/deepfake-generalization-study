# Final experiment inventory (Tier 1 + Tier 2 frozen; Tier 3/4 not run)

Numbers are copied from `master_results.csv`; 83 headline AUCs were independently recomputed from raw saved predictions/scores with zero mismatches (`INTEGRITY_REPORT.md`). Paths are under `outputs/generalization_upgrade/`. "CoAtNet" = code name `hybrid`; "RGB+FFT" = RGB+FFT dual-domain CNN (not a "Frequency CNN"). Historical = target-video-disjoint protocol (historical checkpoints); source-disjoint = `source_video_disjoint_v1` (new training). The two are never pooled.

Conventions: single seed everywhere. CI units: historical FF++ = target-video clusters; source-disjoint FF++ = source-video connected components (26 clusters in the 1,860-frame test set, 30 target groups as a sensitivity check); every external set = image-level bootstrap (external images have no source grouping); reconstruction FF++ subset = source components. AUCs below 0.5 are reported as measured, never inverted.
