## 2. Compatibility assumption (explicit; not a verified fact)
The reconstruction model is the `vae/` component of `stable-diffusion-v1-5/stable-diffusion-v1-5`, pinned to Hugging Face commit `451f4fe16113bff5a5d2269ed5ad43b0592e9a14` (repo last modified 2024-09-07, license creativeml-openrail-m, `diffusion_pytorch_model.safetensors` 334,643,276 bytes). It is used because it is the VAE shipped with the documented generator name. **It must NOT be described as the original generator VAE.** If the dataset authors used a different SD1.5-family VAE or a different decoder, this experiment measures compatibility with a *similar* autoencoder only, and a null/negative result cannot be attributed to the method being ineffective.

## 3. Known limitations that predate results (recorded so they cannot be rationalized afterwards)
1. Identical input handling for both classes is used, but the classes were not identically generated: real photos were small (median face crop 88 px), fakes 512x512 with larger faces. Normalization (five-landmark alignment, resize to 224, JPEG Q90) upsamples real faces more than fake faces. Smoother, more-upsampled images are typically easier to reconstruct (lower error), so reconstruction error is confounded with resolution/blur history.
2. AEROBLADE-type signals rely on the generator decoder's fingerprint in near-pristine images. The normalized external images were cropped, resized and JPEG-compressed at Q90 (and the released fakes were already JPEG). These steps can largely erase decoder-specific traces; a weak or reversed result may reflect that, not the VAE hypothesis.
3. Real and fake differ in source, content, and JPEG history beyond the generator (see Tier 1 bias audit).
4. 576 images (288 pairs) only; one seed (no randomness in this pipeline: posterior mode).

## 4. Score definitions and orientation (FIXED NOW; no sign is chosen after seeing labels)
All are computed per image between the input x and reconstruction x' = Dec(mode(Enc(x))), RGB in [0,1], 256x256.
- **MSE**: mean squared pixel error. Lower = closer reconstruction. Fake-oriented score = **-MSE** (hypothesis: generated images lie nearer the decoder's output manifold, so they reconstruct with lower error).
- **SSIM** (skimage, data_range=1, channel_axis=-1, default 7x7 window): structural similarity, higher = closer. Fake-oriented score = **+SSIM**.
- **LPIPS** (AlexNet, standard full-network LPIPS, not the paper's VGG layer-2 variant): perceptual distance, lower = closer. Fake-oriented score = **-LPIPS**.
- ROC-AUC uses these fake-oriented scores exactly as defined. **A value below 0.5 is reported as measured and NOT inverted.** Raw metric values are also saved.
- These are anomaly scores: no ECE, NLL, Brier, or probability calibration is computed; no threshold is fitted on external labels.
- 95% CIs: image-level bootstrap (2,000 resamples) for the external set (images carry no source grouping; 288 pairs are matched by identity but the pairing is not used to shrink the interval, which is conservative-neutral, not exact). For the FF++ secondary subset, resampling is over source-video connected components.

## 5. Input handling (identical for both classes, no label-dependent branches)
Read the normalized 224x224 RGB crop -> bicubic resize to 256x256 -> float32 [0,1] -> VAE (encode via posterior mode, decode; the diffusion `scaling_factor` is not applied because no UNet is involved) -> clamp to [0,1]. Float32, batch size 4, no augmentation, no randomness.

## 6. Run plan
1. Smoke test on a small balanced subset (dimensions, value ranges, finite scores, determinism across two passes, class-blind preprocessing, example figures). No master-table rows are written by the smoke test.

3. Secondary diagnostic: small predefined FF++ subset (120 frames per label/method group = 600 frames from the source-disjoint test manifest), reported separately and not used to interpret the external result.
